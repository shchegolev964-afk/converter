# 💱 Currency Telegram Bot

Простой и удобный Telegram-бот на Python для:

- просмотра актуальных **курсов фиатных валют и криптовалют**;
- **конвертации сумм** между любыми поддерживаемыми валютами (фиат ↔ фиат, фиат ↔ крипта, крипта ↔ крипта).

Источники данных (бесплатные, без API-ключей):
- [open.er-api.com](https://www.exchangerate-api.com/docs/free) — фиатные курсы (поддерживает RUB, UAH, BYN и др.).
- [fawazahmed0/currency-api](https://github.com/fawazahmed0/exchange-api) — резервный фиатный источник.
- [Frankfurter](https://frankfurter.dev) — второй резерв (данные ЕЦБ; RUB не поддерживает).
- [CoinGecko](https://www.coingecko.com) — криптовалюты.

При недоступности одного из фиатных источников бот автоматически переключается на следующий.

---

## ✨ Возможности

- 🚀 Команды `/start`, `/help`, `/rates`, `/convert`, `/cancel`.
- 🔁 Пошаговый диалог конвертации на `ConversationHandler` (исходная валюта → целевая → сумма).
- 🎛 Удобные **inline-кнопки** с быстрым выбором популярных валют и историей последних использованных.
- 🧠 **TTL-кэш** (по умолчанию 60 секунд) — не дёргает API на каждый чих.
- 🛡 Понятные сообщения об ошибках: неверный код валюты, API недоступен, не-число в сумме и т. п.
- 🪵 Аккуратное логирование, глобальный error handler.
- ⚙️ Конфиг через `.env` (токен, базовая валюта, TTL кэша, уровень логов).
- 🧩 Модульная структура — легко расширять.

## ⚙️ Установка

### 1. Получи токен бота

Открой в Telegram [@BotFather](https://t.me/BotFather), выполни `/newbot`, скопируй токен.

### 2. Склонируй / распакуй проект и зайди в папку

```cmd
cd F:\BOTS
```

### 3. Создай виртуальное окружение и установи зависимости

**Windows (cmd):**
```cmd
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```

**Linux / macOS:**
```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

### 4. Настрой `.env`

Скопируй шаблон и впиши свой токен:

```cmd
copy .env.example .env
```

Открой `.env` и замени `PASTE_YOUR_TOKEN_HERE` на свой токен от BotFather.

| Переменная             | По умолчанию | Назначение                                        |
|------------------------|--------------|---------------------------------------------------|
| `TELEGRAM_BOT_TOKEN`   | —            | Токен бота, **обязательно**.                      |
| `BASE_CURRENCY`        | `USD`        | База для команды `/rates`.                        |
| `CACHE_TTL_SECONDS`    | `60`         | Сколько кэшировать ответы API.                    |
| `LOG_LEVEL`            | `INFO`       | `DEBUG` / `INFO` / `WARNING` / `ERROR`.           |

### 5. Запусти

```cmd
python main.py
```

В консоли увидишь `Бот запущен.` — после этого открывай чат с ботом в Telegram и пиши `/start`.

## 🤖 Использование

| Команда     | Что делает                                                    |
|-------------|---------------------------------------------------------------|
| `/start`    | Приветствие, краткая инструкция, главное меню.                |
| `/help`     | То же, что `/start`.                                          |
| `/rates`    | Курсы популярных фиатов и крипты к базовой валюте и RUB.      |
| `/convert`  | Запускает пошаговый диалог конвертации.                       |
| `/cancel`   | Прерывает текущий диалог.                                     |

### Диалог `/convert`

1. Бот спрашивает **исходную валюту** — можно ввести текстом (`USD`, `BTC`, …) или нажать кнопку.
2. Затем **целевую валюту**.
3. Затем **сумму** (поддерживается `,` и `.` как десятичный разделитель).
4. Бот выводит результат с округлением: **2 знака для фиата**, **до 8 знаков для крипты**.

После результата появляются кнопки «🔁 Ещё конвертация» и «💱 Курсы», чтобы было удобно продолжить.

## 💰 Поддерживаемые валюты

**Фиат:** любые, которые отдаёт Frankfurter — USD, EUR, GBP, JPY, CNY, RUB, CHF, AUD, CAD, …

**Крипта** (расширяется в `bot/config.py` → `CRYPTO_IDS`):
BTC, ETH, USDT, USDC, BNB, SOL, XRP, ADA, DOGE, TON, TRX, DOT.

Чтобы добавить новую монету — найди её `id` на [CoinGecko](https://www.coingecko.com/) и допиши в словарь:

```python
CRYPTO_IDS = {
    ...
    "AVAX": "avalanche-2",
}
```

## 🛠 Troubleshooting

- **`TELEGRAM_BOT_TOKEN не задан`** — забыл скопировать `.env.example` в `.env` или вписать токен.
- **`API ответил 4xx`** — проверь, что код валюты правильный (например, `USD`, не `usd ` с пробелом). Также Frankfurter не отдаёт некоторые экзотические валюты.
- **`API недоступен`** — у CoinGecko бывает rate limit на бесплатном тарифе; кэш помогает, но при большом потоке запросов можно увеличить `CACHE_TTL_SECONDS`.
- **Бот не отвечает** — проверь, что процесс жив (`python main.py` в консоли), и что у тебя только один экземпляр бота (Telegram allows only one long-poller per token).
